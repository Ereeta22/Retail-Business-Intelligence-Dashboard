# Retail-Business-Intelligence-Dashboard


📌 Overview

This is a Power BI dashboard created to analyze retail sales data. It helps understand sales performance, customer details, product categories, and transactions using interactive charts and filters.

🎯 Objective

Analyze retail sales data.
Track customer and sales performance.
Compare product categories.
Create an interactive dashboard for better business insights.

🛠️ Tools Used
Power BI
Power Query
DAX
CSV Dataset

📂 Dataset Columns
Customer ID
Transaction ID
Date
Gender
Age
Product Category
Quantity
Price per Unit
Total Amount

📊 Dashboard Features
KPI Cards (Total Sales, Customers, Quantity, Transactions)
Product Category Filter
Date Filter
Gender Filter
Age Filter
Sales by Product Category
Customer Distribution by Gender
Customer Distribution by Age
Sales Trend Over Time
